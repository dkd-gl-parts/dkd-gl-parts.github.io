# Waybill alignment references

These images are screen-only alignment references for the multipart waybill
layout designer. They are not included in printed output.

- `yamato-takkyubin-collect.webp`: Yamato Takkyubin collect waybill supplied on 2026-09-02.
- `sagawa-hikyaku-collect.webp`: Sagawa collect waybill supplied on 2026-09-02.

The source photographs were cropped to the physical paper edges, rotated to
landscape orientation, and resized to the paper aspect ratio used by D-CATS.
