# 別PC・別アカウントの初回設定

設定 → D-CATS業務連携設定 → 「別PC・別アカウントの初回設定」から取得する。現在の販売王連携と同じ管理者検証範囲で表示する。

初回設定ツールは社内の「D-CATS業務連携／販売王／初回セットアップ」へ置く。共有権限は変更しない。PC版Google Driveが未導入の場合、先に既存のGoogle公式導入手順で本人が接続する。

## 自動で準備する範囲

- 現在のWindows利用者のローカル保存先と、販売王25の導入を確認。
- ドライブ文字を固定せず、指定された共有フォルダーIDの既存同期先を探す。設定済みの保存先を優先し、候補が複数なら停止する。
- 公開情報と実行部品だけを配置。既存ファイルは同一なら再利用し、異なる版は上書きせず管理者へ案内する。
- 現在のWindows利用者専用の終了時バックアップ転送タスクを登録。別アカウントのタスクや、停止設定を変更しない。
- 終了時バックアップの保存先を「販売王／バックアップ／終了時／PC名」とする。

## 本人・管理者が行う範囲

Windows上での初回ツール実行、ブラウザーへの拡張機能追加、Googleの初回ログイン・同意、D-CATS本人確認、端末申請・承認、販売王パスワードの初回登録は本人または管理者が行う。ツールがこれらを自動承認したとは表示しない。

ブラウザーの拡張機能追加では、初回ツールが配置した `%LOCALAPPDATA%/D-CATS/HanbaiOhBridge/extension` を使用する。既存の「拡張機能の管理」案内を利用し、その後D-CATSを更新する。

別のD-CATSアカウントでは、同じWindows利用者の連携部品を再利用できる。端末鍵・本人と販売王IDの対応・パスワードは各D-CATS利用者の既存登録フローで確認し、他の利用者の登録済み資格情報をコピーしない。

PC準備完了はログイン・取込・復元の許可ではない。取込前の保護バックアップ、山本・大西の2名による復旧設定、復元先と実機受入は別途必要。

## 検証の区別

合成Windowsプロファイルで新規設定・再実行・利用者別タスク・競合・保存先不通・停止状態の保持を確認。このPCは読取検査で既存設定の再利用を確認。別PCでの実インストール・ブラウザー拡張の有効化・新規D-CATSアカウントの本人登録は実機未確認。

公開候補 v1.1.1186 は最新mainの並行更新を取り込み、設定入口・利用者切替・バックアップ準備表示・リリース資産の検証を実施。バックアップ準備の検証はCSSクラスではなく固有IDで対象枠を特定し、初回設定枠を追加しても7項目の確認を維持する。

公開用ワークフローと同じ139コマンドをローカルで実行し、全件合格。個々のコマンド内の試験数とは分けて記録する。別PCの受入が未確認のため、入口のPRはドラフトを維持する。
