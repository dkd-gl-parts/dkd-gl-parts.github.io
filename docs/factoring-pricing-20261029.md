# ファクタリング売値区分

既存5区分を保持し、RECYCLE_FACTORING（ファクタリング）を追加する候補。公開前に対応するDB変更の適用が必要。

販売価格設定の「ファクタリングの計算条件」ボタンから専用画面を開き、消費税率・ファクタリング手数料率・MP（マーケットプレイス）販売手数料率・送料配賦率・切上げ単位を変更できる。戻ると販売価格設定へ復帰し、未保存の変更は確認して破棄する。売値区分1を基準に業販とモールの価格を計算し、高い方を共通販売単価とする。基準未登録・条件取得失敗は価格未登録として表示する。

画面の試算はBigIntの分数計算を使用し、掛率の中間丸めをしない。顧客カタログ・商品詳細・価格表・受注候補にはサーバーから返された最終単価を使用する。Recycle+受注の入力済み成立単価や、登録済み伝票の単価は上書きしない。

管理権限がある利用者のみ条件を保存可能。変更は全商品に影響するため画面内に範囲を明記する。同時編集はrevisionで拒否し、通信結果不明時は保存結果の照会を促す。再試行は利用者が選んだ場合に同じID・同じ内容だけを送る。利用者変更・ログアウト・権限喪失後の応答は反映しない。

検証:

- 別画面化後も正式workflowから抽出した158コマンドが成功（構文・配信ビルド・headers含む）。新規価格テスト108項目、Recycle+76項目。
- 保存結果不明のまま管理権限を失った場合は、確認情報を残して閉じることができる。再び管理権限で開いたときに照会し、勝手に再送しない。
- 非表示IABで1280×720、390×844を確認。モバイル実測document/body幅390、専用dialog幅356、横はみ出しなし。戻るとボタンへフォーカスを戻し、Tab移動とEscapeによる閉じ方を検証。
- 合成基準5,800円→7,100円。手数料6%→7%で7,200円に保存・再計算。
- 閲覧専用、読込中、通信失敗、結果不明からの照会、価格未登録、セッション終了、Tab移動を確認。console error/warningなし。
- 所有タブを閉鎖、viewportをreset。通常Chrome/Edge・利用者セッション・ポインター・クリップボードへの操作なし。

この確認は合成UIと隔離DBによる検証。本番リリース・実顧客アカウントによる受注確認とは区別する。候補版数はv1.1.1259。並行する未公開PRにも同候補版数があるため、統合直前にmainと版数を再確認する。
