# Recycle＋向け販売価格表

販売価格表の「価格表の種類」で「得意先向け」と「Recycle＋向け」を切り替える。Recycle＋向けは得意先選択が不要で、カテゴリ・商品区分・品番で絞り込める。提供されたRc+ロゴを条件欄とPDFに表示する。

価格は既存ファクタリング価格区分を使用する。現行基準価格がある商品を候補とし、未設定・0円の価格は掲載しない。得意先別の公開設定は使わないため、掲載品番を確認する案内を表示する。計算条件や顧客割当・既存受注は変更しない。

プレビュー・PDF発行・履歴の再表示は同じ画面を使用し、種類ごとに履歴を読み込む。Recycle＋のPDF表題と保存名は「Recycle＋向け販売価格表」。日付は保存済みの発行日時の日本時間を使う。料率・原価等の内部情報は印刷しない。

発行時はサーバーで価格と設定版を再確認し、プレビューが古ければ更新を求める。通信切断などで発行結果が不明な場合、条件変更や再送を止め、「発行結果を確認」で保存済みの結果を照会する。履歴は発行時の価格を維持し、別の利用者へ切り替わった場合はその利用者の結果だけを扱う。

依存する私有サーバー変更: dcats-security の 20261029074424_recycle_plus_price_report.sql。サーバー変更の適用を確認してから画面を公開する。既存の得意先向けAPIと履歴は維持する。
