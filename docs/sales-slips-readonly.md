# 売上伝票の一覧・詳細（閲覧専用）

本番未適用・公開前の候補。売上計上機能のOFF設定は変更しない。

## 利用者の操作
受注・出荷管理の「売上伝票を確認」から一覧を開く。伝票番号・得意先コード/名称、売上日、売上/取消で検索する。1ページ50件、ID順の次ページ方式。伝票番号から保存済みの明細を表示する。元伝票/赤伝票の相互参照のみを提供し、登録・修正・取消・印刷・請求・入金操作は提供しない。

## 読取契約
- RPC: list_sales_slips_readonly(p_search,p_from,p_to,p_slip_type,p_before_id,p_limit)、get_sales_slip_readonly(p_slip_id)。
- 応答: contract_version=1、posting_enabled(boolean)。一覧は rows, has_more, next_before_id。詳細は status=found/not_found、found時は slip, items。
- 実装SQL候補は別途private側で管理する。本PR単独ではAPIを追加しない。未適用APIは「準備中」と表示し、0件扱いしない。
- 有効な内部利用者・受注管理権限・完成品出荷権限をサーバー側で確認する。system_admin以外は本人の会社の伝票だけを返す。会社範囲をブラウザ入力から採用しない。
- bigintのID・金額は十進文字列。得意先コードの先頭ゼロを保全。画面で金額計算は行わない。
- 締め時一括では税抜金額/税額/合計がnullのまま「締め時に確定」。未確定原価はnullのまま「未確定」。赤伝票の符号も保存値を表示する。
- 画面離脱、ログアウト、利用者変更、権限失効、検索/明細の応答逆転で古い結果を破棄する。
- 元の売上SQL・SQL試験・保護ルール・実データ・機能フラグは変更しない。018以降の旧作業は凍結のまま。
