# D-CATS業務連携の設定画面

## 利用する場所

- 日常の操作: 受注・出荷管理 → データ連携 → 業務連携。
- 初回登録や設定変更: メニュー → 設定 → D-CATS業務連携設定。
- 日常の画面の「業務連携設定を開く」からも設定へ進める。そこから閉じると日常の画面へ戻る。

## 設定画面へ移した項目

- フォルダのショートカット取得とPC版Google Driveの導入・同期ヘルプ。
- 販売王パスワードの初回登録・再登録。
- 取込前バックアップ準備の確認、Google接続とバックアップ用パスワード登録。
- B2 CSVの保存先確認・許可、保存先変更時の注意と実際のリンク先表示。

共有フォルダの利用と、商品台帳・得意先台帳・売上の個別出力は日常の画面に残す。
設定を開くだけで販売王の起動、データ取込、Google認証、パスワード登録は始めない。

## 権限・中断

メニューの設定入口は既存の受注・出荷管理権限に従う。販売王の登録・バックアップ準備・管理者検証は従来どおりsystem_adminだけに表示し、サーバーと端末の認可も維持する。
秘密入力は端末の保護された専用GUIで行う。閉じる、利用者変更、セッション失効で進行中処理の許可を失効させる。結果不明の書込みを再送しない。

## 検証・公開

- 既存の連携・登録・保存先検査に加え、`verify-business-workspace-settings.js`で画面分離、無操作時の非実行、権限、中断、利用者変更、フォーカス復帰を確認する。
- Search performance guardの全検査、static build、CSP/response headers、資産バージョン一致を公開条件にする。
- 非表示IABの合成画面を1280pxと320pxで確認。日英中、未準備、準備済み、連携アプリエラー、一般担当者・得意先、Tab/Shift+Tab/Escapeを確認する。実認証情報や販売王データは使用しない。
- 実装前のmain: `eeec65a`。UI差分のrevertと再ビルドで以前の配置へ戻せる。DB/秘密設定/Native hostの変更は不要。
