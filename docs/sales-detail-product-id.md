# 販売管理の商品詳細に商品IDを表示

商品IDは既存の見出し行に配置し、独立した1行を増やさない。PCでは品番と同じ行、スマホではカテゴリと同じ行に表示する。値は既存productDkdId、未設定は「-」、日英中のラベルとHTMLエスケープを共用する。

PCの販売条件は得意先と商品区分、販売価格と在庫をそれぞれ横に並べ、基本情報のメーカー・仕様欄も幅に応じて整理する。必要な項目と文字サイズを維持したまま、詳細下段全体の追加スクロールを解消する。高さの低いPCでは互換品一覧の表示高を調整する。本人指定に従い互換品一覧内の既存スクロールは維持し、ページ切替には変更しない。

レイアウト変更は[レイアウト最優先条件](layout-policy.md)に従う。内容をクリップしたりスクロールバーを隠すだけで完了扱いにしない。

検証はPC6寸法×日英中18表示、商品区分と得意先の選択、長い品番、スマホ390/320pxでの可視確認を含む。全体CI・本番配信・実画面の結果はPRと作業記録に記録する。
