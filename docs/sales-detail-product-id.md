# 販売管理の商品詳細の配置

商品IDは既存の見出し行に配置し、独立した1行を増やさない。値は既存productDkdId、未設定は「-」、日英中とHTMLエスケープを共用する。

得意先コンボは販売条件の左列を広く使う。商品区分・販売価格・在庫数の項目名は同じ左端の縦1列へ揃え、各項目の順序を維持する。在庫数と棚番だけは左右の等幅2列とし、棚番を在庫数の右側へ配置する。狭幅では等幅を保ち、ラベルと値を上下に折り返す。

基本情報は従来どおり、車メーカー・純正品番・GLTEK品番の下へメーカー・メーカー品番・仕様を縦に配置する。メーカー情報を横へ移さない。高さの低いPCでは文字サイズを維持したまま縦余白を調整する。

[レイアウト最優先条件](layout-policy.md)に従い、詳細下段全体の追加スクロールを防ぐ。本人指定の互換品一覧内の既存スクロールは維持する。データ取得・価格計算・在庫・権限は変更しない。検証・本番確認の結果はPRと作業記録へ保存する。

販売条件の得意先・商品区分・販売価格は行高と上下余白を揃え、在庫数と棚番の等幅配置を保持する。低いPCでは行の余白だけを詰め、日英中の長い送料条件・コア条件ラベルも読める幅を確保する。ヤマト運輸を選択した送料試算では離島送料欄を表示しない。通常送料・税区分・一般の注意事項、および他社の離島送料は維持する。

販売管理の商品詳細上段にはメーカー名/メーカー品番の重複行を表示しない。主品番・商品ID・カテゴリ・在庫等のバッジ・保証は維持し、メーカー名/メーカー品番は基本情報で確認する。検索結果カードの表示は変更しない。モバイルは削除行の空き段を残さず、状態と保証を詰めて配置する。

送料区分は販売条件の左側へ集約し、得意先未選択時も既存の既定区分「送料別途」を表示する。別途送料で都道府県未選択の場合は左側に案内ボタンと矢印を表示し、送料一覧の都道府県欄へスクロールしてフォーカスを移す。横並びでは右矢印、縦並びでは下矢印。選択欄を淡色で示し、選択後は案内と強調を消す。右欄下段に同じ未選択文言を重複させない。送料込み/権限なし/読込中/空/取得失敗には案内を出さず、サイズ未選択の既存案内は保持する。料金・税・離島・顧客の保存設定は変更しない。
