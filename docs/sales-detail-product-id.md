# 販売管理の商品詳細に商品IDを表示

メーカー品番の下に「商品ID」を表示する。既存のproductDkdIdでDKD商品IDを取得し、IDがない場合は「-」。日英中の既存ラベルとHTMLエスケープを共用する。商品種別の切替で商品IDは変えない。

画面表示のみの変更。保証期間、棚番、在庫、価格、編集権限、データ取得方法は既存のまま。PC1280px・スマホ390/320px、日英中の9表示とIDの優先順位/代替/未設定/HTMLエスケープを非表示ブラウザで確認。既存保証70項目、出荷29+棚番35項目、共通UIの検証が成功。全体CIおよび本番反映・本番画面確認はPR/作業記録へ記録する。
