# TD-4420TN スマホ印刷ステーション

D-CATSのスマホ画面で「登録・印刷」を押すと、専用Windows印刷端末が認証済みジョブを自動受信し、Brother TD-4420TNへ出力します。初回設定後の日常操作はスマホだけで完結します。

## 採用する運用

- TD-4420TNとWindows PCを1台、完品シール45×20mm専用にします。
- Windowsへサインインすると印刷端末が自動起動し、受信も自動で始まります。
- 一度受信を開始した端末では、D-CATSの更新やブラウザー再起動後も受信中へ自動復帰します。停止ボタンまたはログアウトを行った場合は自動復帰しません。
- Edgeを閉じても監視スクリプトが再起動します。
- 専用印刷端末として動作中は、D-CATSの通常の8時間無操作ログアウトを停止します。
- スマホは自分が送信した印刷ジョブの状態を追跡し、完了・エラー・応答なしを表示します。
- 通信が一時的に切れたり応答待ちになったりしても、同じジョブを再確認するため二重印刷を作りません。

## Windowsの初回設定

1. WindowsへBrother TD-4420TNの公式ドライバーをインストールします。
2. ドライバーの用紙サイズを`45 × 20 mm`、倍率100%、余白なしに設定し、Windowsからテスト印刷します。
3. `scripts/install-td4420tn-print-station.ps1`と`scripts/start-td4420tn-print-station.ps1`を同じフォルダーへ保存します。
4. PowerShellを開き、保存先で次を実行します。

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\install-td4420tn-print-station.ps1 -LabelTarget finished_product -PreventSleep -LaunchNow
```

5. 開いた専用Edge画面で、完品シール権限のある社内ユーザーとしてD-CATSへ一度だけログインします。
6. 「印刷待ちを監視中」と表示されることを確認します。

インストーラーはオンラインのTD-4420TNを自動検出して、このWindowsユーザーの既定のプリンターに設定します。複数台のTD-4420TNがある場合は`-PrinterName "Brother TD-4420TN"`のように正確なプリンター名を指定します。Windowsが既定のプリンターを自動変更する設定も無効にし、起動スクリプトを`%LOCALAPPDATA%\D-CATS\TD-4420TN-PrintStation`へコピーして、現在のWindowsユーザーのスタートアップへショートカットを登録します。`-PreventSleep`はAC電源使用時のスリープを無効にします。

## 「Windows端末を常時起動」の意味

24時間起動する必要はありません。印刷する時間帯に、Windowsへサインイン済みで、PCとTD-4420TNの電源が入り、PCがスリープしていない状態にします。画面だけが消えることは問題ありません。Windows再起動後は、そのWindowsユーザーへのサインインが必要です。

## スマホ側の操作

- 完品シールは「登録・印刷」を押すと、製造シリアルと完品在庫を登録してから印刷します。
- 再印刷は既存の製造シリアルを使い、在庫を増やしません。
- 「印刷指示完了」が出るまで画面がジョブを追跡します。
- キオスク印刷モードのWindows印刷端末が受信中であれば、新しいキューを約4秒以内に検出し、印刷ボタンを押さずに登録順で自動印刷します。複数件の待機がある場合は間を空けずに続けて処理します。
- 「Windows印刷端末から応答がありません」と表示された場合もジョブは保持されています。Windows端末を復旧してから同じ画面の「印刷を再試行」を押します。

## 印刷完了の意味

D-CATSの「印刷指示完了」は、Windowsの印刷処理へデータが渡された状態です。用紙切れ、リボン切れ、紙詰まりなどTD-4420TN本体の物理状態はプリンター本体でも確認してください。

## 箱シールへ切り替える場合

箱シール80×60mmへ切り替えるときは、TD-4420TNのロールとBrotherドライバーの用紙サイズを80×60mmに変更し、インストーラーを次のように再実行します。

```powershell
.\install-td4420tn-print-station.ps1 -LabelTarget box -PreventSleep -LaunchNow
```

再設定後はWindowsから一度サインアウトしてサインインし直し、箱シール用の印刷端末として起動したことを確認します。

1台のTD-4420TNで45×20mmと80×60mmを同時受信しないでください。日常運用を最も簡単にする場合は、用紙サイズごとにプリンターとWindows印刷端末を分けます。

## セキュリティと復旧

- 印刷専用のWindowsユーザーと、完品シール権限だけを付けたD-CATS社内ユーザーを使用します。
- Windowsを離れるときは画面をロックし、端末の物理アクセスを制限します。
- 同じ完品登録・同じシール種別の処理中ジョブは二重作成しません。
- Windows印刷端末でエラーになったジョブは、印刷端末の履歴から再試行できます。
- 通常のEdgeでは印刷確認画面が表示されます。付属スクリプトは専用Edgeプロファイルと`--kiosk-printing`を使用し、Windowsの既定のプリンターへ確認画面なしで送信します。
