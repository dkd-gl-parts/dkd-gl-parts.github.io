# TD-4420TN スマホ印刷ステーション

D-CATSのスマホ版はプリンターへ直接出力せず、認証済みの印刷待ちへジョブを登録します。Brother TD-4420TNのドライバーを設定したWindows PCがジョブを1件ずつ受信して印刷します。

## 初回設定

1. WindowsへBrother TD-4420TNの公式ドライバーをインストールします。
2. TD-4420TNをWindowsの既定のプリンターに設定します。
3. ドライバーの用紙サイズを、使用するシールに合わせて `45 × 20 mm` または `80 × 60 mm`、倍率100%、余白なしに設定します。
4. PowerShellで `scripts/start-td4420tn-print-station.ps1` を実行します。
5. 開いたD-CATSへ社内ユーザーでログインし、`完品登録・シール印刷` → `Windows印刷端末` を開きます。
6. 画面の「現在セットしている用紙」を実際のロールと一致させ、`印刷待ちの受信を開始` を押します。

45×20と80×60を切り替えるときは、受信を停止してから用紙ロールとBrotherドライバーの用紙サイズを変更し、D-CATS側の用紙選択も変更してください。同じプリンターでも、異なる用紙サイズのジョブを同時には受信しません。

## 運用ルール

- スマホの `登録・送信` は、製造シリアルと完品在庫を登録した後、完品シールを印刷待ちへ送信します。
- 送信エラー時の `印刷待ちへ再送` は同じ完品登録を再利用するため、製造シリアルや在庫を増やしません。
- 同じ完品登録・同じシール種別に処理中のジョブがある場合、重複ジョブは作成されません。
- 印刷端末でエラーになったジョブだけ、履歴の `再試行` から印刷待ちへ戻せます。
- 画面の `送信済み` はOSの印刷処理が完了した状態です。用紙切れやリボン切れはTD-4420TN本体でも確認してください。

通常のEdgeで印刷端末を開くと印刷確認画面が表示されます。付属のPowerShellスクリプトは専用Edgeプロファイルと `--kiosk-printing` を使用するため、Windowsの既定プリンターへ確認画面なしで送信します。
