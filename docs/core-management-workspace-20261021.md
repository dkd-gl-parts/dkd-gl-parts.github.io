# コア管理の収集・在庫ワークスペース

収集リストは買い集める対象、現在庫は保管中のコアとして説明を付け、切替ボタンから目的を判断できるようにした。品番検索・絞り込みと、追加・ランキングからの追加・CSV出力を分離した。

収集リストのサマリーは取得済みの検索結果について、対象品番・目標数・現在庫・不足数を単位付きで表示する。保留・完了を含むことと表示件数を明記する。在庫画面は読み込み済み明細数とコア合計を表示し、続きがある場合を区別する。算式・並び順・検索条件の意味は既存どおり。

PCは品番と数量を強調する表、768px未満はカードを使う。モバイルの詳細条件は開閉でき、有効な条件の数を表示する。追加元・メモを開閉し、登録・編集・完了・削除・写真・CSVの既存処理と権限を保持する。タブは矢印・Home・Endで操作でき、選択状態とフォーカスを示す。

読み込み開始時は古い集計を消し、取得失敗時はゼロ在庫と表示しない。検索から再試行でき、未取得・失敗中のCSVを無効にする。タブ切替や再検索より古い応答は一覧・集計・在庫マップへ反映しない。DB・業務データ・権限・認証・CSPは変更しない。

検証: 正式search-performance workflowの全151コマンド、28項目の実関数による操作・遅着・失敗回帰、security workflowの追加検査を実施。非表示IABで日英中×PC1280/モバイル390×両画面12描画、読込/空/エラー/在庫取得失敗/期限切れ/閲覧専用/権限不足と再試行を確認。合成データを使用し、本番の書込み操作を検証のために実行しない。
