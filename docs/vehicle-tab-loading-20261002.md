# 商品詳細「適合車両」の読み込み停止（2026-10-02）

## 症状と調査

商品 `31100-PEJ-004` の適合車両タブが「読み込み中…」から進まない。適合データの補完を切り戻しても再現した。Supabase のブラウザ向けログでは `get_catalog_vehicle_applications` と `catalog_vehicle_applications` の取得が HTTP 200 で完了していた。

商品詳細は適合車両・配送情報などを並列に読み込む。配送情報の完了時に `currentProduct` を新しいオブジェクトへ差し替える一方、適合車両の完了時は古いオブジェクトとの参照同一性で表示可否を判定していた。この順序になると取得済みの適合行が画面へ反映されず、「読み込み中…」が残る。

## 修正

- 商品詳細のリクエスト連番と DKD 商品 ID で、結果が現在選択中の商品に属するか確認する。古いリクエストの表示は抑止する。
- 取得処理が例外を投げた場合は読み込み表示をエラー案内へ変え、再度商品を開けるようにする。
- `v1.1.1081` へ更新し、変更した JavaScript がキャッシュから旧版として使われないようにする。

## 検証と公開

- `scripts/verify-partsfan-research.js` で配送情報による商品オブジェクト差し替え、古いリクエスト、取得失敗を再現して検証。
- `node --check app.js`、適合車両・商品詳細・配送情報・版番号のガード、静的ビルド、セキュリティヘッダーの検証が通過。
- Windows ローカルのワークフロー全件実行は、変更していない `styles.css` の CRLF 改行を既存のガードが受け付けず途中停止。Linux CI の全件結果を公開前に確認する。
- 本番公開後、対象商品でタブが表示されることを確認し、適合データ補完はその後に再適用する。
