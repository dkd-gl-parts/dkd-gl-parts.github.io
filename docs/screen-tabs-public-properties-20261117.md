# 画面タブの社内公開とプロパティ（v1.1.1348）

本人の公開指示により、確認済みの社内アカウントへ公開。初期OFFで、メニューの「設定」内にある「画面タブ」カードから、このブラウザーでの利用をON/OFFし「適用して閉じる」で反映する。従来の挨拶下の試験用スイッチは移動する。保持上限9/FIFO/未保存確認/再読込時の画面・順番復元は維持し、同画面で説明する。外部顧客・プロフィール未取得・実Auth未確認は対象外。

未保存入力があるOFFは事前確認し、取消はONと入力を保持する。保存中/結果未確認はOFFにせず、設定画面で確認できる。プロパティ自体は保持タブに数えず、設定変更は業務の入力変更に数えない。入力内容そのものは再読込で復元しない。

狭い画面のタブ列は前後のページボタンで切り替え、隠したスクロールバーに依存しない。タブ順・選択はページ切替で変えない。タブ列35pxと元のメニューを維持する。「画面タブ」は「D-CATS業務連携設定」と同じカード描画・同じ枠内に置く。見出し横の旧ボタンは削除する。プロパティ全体はPC/低いPC/スマホで必要な項目と操作を収める。

入口の閲覧条件・サーバー認可/DBは変更しない。本人は今回の公開について合成fixtureの権限拒否確認を採用した。実Authの本番確認には指定の業務点検アカウントを使用し、同アカウントを低権限として扱わない。

停止はpolicy.mode=off、山本限定へ戻す場合は直前pilot設定を復元する限定PR。差分レビュー/既存CI/配信一致/専用headless確認を行い、他のmain変更を巻き戻さない。

タブの機能名の左には、同じメニューのアイコンを表示する。絵文字と既存の画像アイコンを共用し、アイコンを固定リストや保存データへ追加しない。装飾アイコンは読み上げ対象外とし、タイトル・閉じるボタンの読み上げ名は機能名のまま。35pxの高さ、9/FIFO、ページ切替、未保存確認と既存の長い名称の省略表示を維持する。
