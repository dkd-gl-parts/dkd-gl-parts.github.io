# バックアップ用パスワードの確認（v1.1.1139）

メニューの設定枠「D-CATS業務連携設定」に「保存したバックアップ用パスワードを確認」を追加。

登録時と同じD-CATSアカウントで専用画面から本人確認（設定済みならMFAも）を行い、現在の会社・端末・権限をサーバーで再確認する。このPC・Windows利用者で暗号化保存したバックアップ用パスワードを、伏せ字から明示操作で30秒間表示する。別画面へ移ると隠し、3分後に表示用内容を消去して終了。保存がない場合の案内も追加。

ブラウザへパスワードを返さない。ブラウザの起動許可だけでは復号できない。登録・確認は排他的に指定し、全操作中は既存の連携操作を無効化する。パネル終了、利用者切替、署名/端末不一致、拡張不通時には停止し、秘密のエラー内容は表示しない。

現在のPC内保存が対象。PC故障・交換時の共有復旧設定、復旧担当者、本登録、実運用バックアップ/取込の準備は別途必要。旧バックアップに新パスワードが適用されたとは案内しない。

検証: 公式workflowの128検証、隔離された非表示ブラウザで3言語×3幅の確認・結果・終了/不通・権限非表示65項目。実認証・販売王操作0。配布にはこのPCの拡張機能0.5.10の再読み込みが必要。
