# 棚とパレティーナの場所別管理

在庫管理の「棚・パレティーナ管理」から利用します。棚はT01〜T03、各棚は下から01〜06の18か所です。

1. 必要なパレティーナ番号（例GLS-23）を登録します。
2. 品番・商品区分で商品を検索し「場所を見る」を開きます。
3. 「既存在庫の場所を登録」で、未割当から保管場所へ数量を割り当てます。元の入荷・パレット番号とコンテナ回数が分かる場合は入力します。
4. パレティーナから棚などへ動かすときは「移動」を選びます。元の入荷番号と回数は引き継がれます。
5. 場所の登録だけを訂正するときは「解除」で未割当に戻します。出庫は従来の在庫管理で記録してください。

新品とリビルトは別の在庫として選択します。場所の操作では合計在庫は変わりません。場所登録数が合計在庫を超えている場合は要照合と表示します。現物と合計在庫を確認し、場所別数量を訂正してください。

通信が途切れて結果が分からない場合は、再送せず「結果を確認する」を使います。依頼IDは同じアカウントのブラウザセッション内に保存されます。結果がまだ見つからない場合も新しい保存は止め、依頼IDを控えて管理者へ確認してください。

従来の出庫・棚卸などで合計在庫が減った場合、登録済みの場所は「要実数確認」になります。実物を数え、各場所の「実数確認」で数量を確定してください。確認が終わるまで追加登録と移動を止めます。実数確認では合計在庫を変更しません。同じ棚に異なる入荷元の品物を置く場合は、箱や仕切りにも入荷番号を表示してください。

作業理由・メモは任意です。場所登録・移動・解除・実数確認は空欄のまま保存できます。一括登録CSVも「作業理由」列を空欄にできます。入力したメモは履歴に残ります。
