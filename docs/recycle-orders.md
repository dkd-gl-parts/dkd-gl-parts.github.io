# Recycle+受注・精算

受注・出荷管理の「Recycle+受注入力」から利用する社内向け機能です。
開くと受注入力を表示します。得意先はブロードリーフで固定し、得意先発注と同じ注文内容・お届け先の配置を使います。
「設定」「精算一覧」は上部のボタンから別画面を開き、「受注入力に戻る」で戻れます。
画面の移動では入力途中の注文・商品・数量・単価・お届け先を保持します。閉じる際には未保存入力を確認します。
初回登録前も入力画面を表示しますが、登録完了まで入力を無効にし、設定への案内を表示します。
利用開始には対応するDBの適用と、以下の初回設定が必要です。

1. システム管理者がD-CATS内の集約先「ブロードリーフ」を一度だけ登録します。
   販売王の得意先コードは未登録です。社内コードBROADLEAFを販売王コードには使用しません。
2. Recycle+注文番号、注文ごとの直送先、商品、数量、成立した税抜商品単価と送料を入力します。
   通常の得意先価格ランクから価格を上書きしません。
   商品は品番検索で追加します。郵便番号の住所検索、お届け希望日・時間帯、必要な商品のコア返却便も指定できます。
   住所検索中に郵便番号や住所を編集した場合、遅れて届いた結果で編集中の住所を上書きしません。
3. 登録後、外部の決済完了明細と注文・金額・直送先を照合し、完了日時、参照番号、確認根拠を記録します。
   未確認の受注は出荷指示・発送用送り状・出荷確定へ進めません。
4. 決済確認後は既存の出荷工程を使用します。確認後の金額・直送先・明細変更は制限されます。
   送り状等の出荷処理開始前に限り、理由を付けて決済確認を解除できます。
5. 精算明細が届いたら、控除額合計としての確定手数料、判明していればうち税額、明細番号を記録します。
   見込額・確定額・差引受取額を分けて確認します。

暫定の手数料率は10％です。見込算定の初期条件は「商品税抜額・送料とコア代を除外・円未満切捨」です。
これらは正式契約を確定した扱いにはしません。システム管理者が料率、算定対象、包含項目、端数、
暫定表示、確認根拠を変更でき、変更は新しい受注に適用します。過去受注は登録時の条件を保持します。

一覧は受注日で集計します。精算月・売上月の集計とは区別してください。
「確認用CSV」は表示中の最大100件の照合用であり、販売王取込形式ではありません。
販売王連携は、正式なブロードリーフ得意先コードと決済済み売上の取込方式を確認してから接続します。
それまで通常の掛売CSVへの混入を止めます。

保存の応答が途切れた場合は再送せず、「結果を確認」を使用します。
画面を再読込する前に結果を確認してください。注文番号の重複はサーバーでも拒否します。
取消後の返金確認は、外部で返金が完了した事実の記録です。D-CATSから送金は行いません。

この段階は手入力と外部明細との照合です。Recycle+の注文API・CSV自動取込・決済自動通知、
出荷後の独立した売上値引伝票、販売王実取込は含みません。
